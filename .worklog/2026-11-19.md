## 주요 결정 사항

- **상품 선택: 상품 종류를 안 골라도 전체 상품에서 검색 가능하게 함.**
  기존에는 상품 종류를 먼저 골라야 상품 칸이 열렸음. 검색이 생기면 종류부터 고르는 단계가 오히려 번거로워서,
  종류 미선택 시 전체 검색 + 목록에 종류 표시(같은 이름 상품 구분: 팔각정 2개, 인쇄 2개) + 상품을 고르면 종류 자동 채움.
  종류를 먼저 고르면 기존처럼 그 종류 안에서만 검색. 되돌리려면 `OrderItemCard` 의 ProductCombobox `products`/`disabled` 만 바꾸면 됨.
- **상품 콤보박스는 기존 CustomerCombobox 와 같은 방식(Popover + cmdk)으로 새 컴포넌트 `ProductCombobox` 로 분리.**
  OrderItemCard 는 새 주문 등록 / 작업 추가(AddWorkOrderDialog) / 작업 수정(EditWorkOrderDialog) 세 곳에서 쓰여 모두 적용됨.
  작업 수정은 `lockProduct` 로 기존처럼 상품 변경 불가.
- **검색 로직은 `src/lib/search.ts` 의 `filterByName` 하나로 통일** (대소문자·앞뒤 공백 무시). 옵션 검색과 상품 검색이 같이 씀.
- **옵션 검색어는 옵션 설정 모달을 열 때마다 초기화.**
- **테스트 버전**: Vite 5 와 맞는 Vitest 3.2, jsdom 26. jest-dom 은 6.10.0 이 "breaking change 가 들어간 잘못된 릴리스" 경고가 있어 6.9.1 로 고정.
- **테스트 설정은 `vitest.config.ts` 로 분리.** 저장소에 vite.config.js / .ts 가 둘 다 있어서(개발 서버는 .js 를 먼저 읽음) 거기에 섞지 않음.
- 패키지 매니저는 yarn 1 사용 (yarn.lock, Vercel 빌드 기준). CLAUDE.md 의 npm 명령 안내와 다름.
